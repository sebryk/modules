# Страница сотрудника и локальное редактирование

## Цель

Из командной таблицы можно открыть отдельную страницу любого сотрудника, посмотреть его данные и изменить их на фронте. Пользователя также можно удалить без обращения к backend.

## Пользовательский сценарий

- Клик по имени сотрудника открывает маршрут `/team/:employeeId`.
- Страница сохраняет текущую визуальную систему приложения: Mantine-компоненты, существующие цвета, типографику, радиусы и светлую/тёмную тему.
- В верхней части есть возврат к списку и хлебная навигация «Сотрудники → Имя».
- В карточке профиля отображаются фото, имя, фамилия, email, должность и статус.
- Если фото отсутствует, показывается заглушка на базе `Avatar` с инициалами сотрудника.
- Форма редактирования содержит имя, фамилию, email, должность и статус. Кнопка «Сохранить изменения» обновляет локальное состояние.
- «Удалить сотрудника» требует подтверждения. После удаления пользователь возвращается на таблицу, где запись отсутствует.
- При неизвестном `employeeId` показывается понятное состояние «Сотрудник не найден» и ссылка обратно к команде.

## Архитектура

- Добавить маршрут `team/:employeeId` рядом с маршрутом команды.
- Вынести состояние сотрудников в небольшой Zustand store, инициализированный текущими mock-данными. Таблица и страница сотрудника используют один источник состояния.
- Сохранение формы обновляет запись по `id`; удаление удаляет запись из store. Backend/API не изменяются.
- Список должностей и статусов переиспользует существующие типы и словарь подписей.
- Действие «Редактировать» в меню таблицы ведёт на страницу сотрудника; действие «Удалить» использует то же подтверждение и локальное удаление.

## Компоненты и состояния

- `TeamPage`: читает сотрудников из store, сохраняет текущие поиск, сортировку и пагинацию, добавляет ссылки на карточку и рабочие удаления.
- `EmployeePage`: получает `employeeId` из маршрута, отображает профиль и форму, обрабатывает сохранение/удаление.
- Локальные состояния формы не меняют таблицу до сохранения.
- После сохранения остаёмся на странице и показываем уведомление об успешном обновлении.
- После удаления показываем уведомление и переходим на `/team`.

## Проверка

- TypeScript build/typecheck и lint.
- Ручная проверка: открыть сотрудника из таблицы, изменить данные, обновить страницу маршрута в рамках dev-сессии, удалить сотрудника из карточки и из меню таблицы, проверить пустой/неизвестный id и отображение заглушки фото.

## Ограничения

- Фото пока только отображается из локального поля, загрузка файла не входит в задачу.
- Данные не переживают перезагрузку браузера, так как backend не подключается.
