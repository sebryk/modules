# Frontend

React, TypeScript и Vite. Требуется Bun 1.4.2.

```bash
cd frontend
bun install --frozen-lockfile
bun run dev
```

Проверки и сборка: `bun run lint`, `bun run typecheck`, `bun run build`.

## Сотрудники

Страница `/team` получает список из `GET /users` через общий авторизованный
API-клиент. Адрес бека задаётся в `VITE_API_URL`, по умолчанию используется
`http://localhost:3000`. Требуется разрешение `user:read` и применённая миграция
полей пользователя на беке.

Поиск (с задержкой 300 мс), фильтры, сортировка и пагинация отправляются в API.
Строки и количество страниц берутся из серверных `data` и `meta`; моковые записи
при ошибках не подставляются. Кнопки создания, редактирования и удаления на этой
странице временно отключены. Отдельная карточка сотрудника пока сохраняет прежнюю
реализацию и не открывается из таблицы.
